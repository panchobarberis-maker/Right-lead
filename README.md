# RightLead

Landing page estática (un solo `index.html`, sin dependencias ni build).

## Ver en local

Abrí `index.html` en el navegador, o serví la carpeta:

```bash
npx serve .
```

## Deploy en Vercel

El repo ya está listo para importarse tal cual:

1. Entrá a https://vercel.com/new
2. Importá el repo `panchobarberis-maker/right-lead`
3. Framework Preset: **Other**
4. Build Command: vacío · Output Directory: vacío (raíz) · Install Command: vacío
5. Deploy

Cada push a la rama conectada genera un deploy nuevo automáticamente.
